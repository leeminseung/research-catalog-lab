# Which Agent Causes Task Failures and When? On Automated Failure Attribution of LLM Multi-Agent Systems

Authors: Shaokun Zhang et al., 2025

Link: https://arxiv.org/abs/2505.00212

Coordination pattern: Post-hoc failure attribution along inter-agent handoff chains — localizing which agent and which step broke a coordinated run.

## Why it belongs

It turns coordination failure analysis into a measurable benchmark problem, with the Who&When dataset of 127 annotated multi-agent failure logs that attribution and recovery work now trains and evaluates against. Complements MAST's taxonomy with automated localization.
