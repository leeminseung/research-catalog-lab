# Research catalog

A catalog of papers on multi-agent coordination. Each paper is one Markdown file under `entries/`.

New entries arrive as pull requests opened by a research intake routine: workers gather candidates from alphaXiv, OpenAlex, arXiv and GitHub, an editor screens them, a person approves the list, and the writer opens the pull request. A person reviews and merges. Nothing writes to `main` directly.

This repository is a test bed. The routine and worker definitions live in a separate, private repository.
